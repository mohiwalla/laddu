Install laddu on your Linux server

$curl -fsSL https://laddu.wtf/install.sh | sh
  1. 01 Runs on any Linux server with systemd and installs Docker and Bun if missing. Already have them? Run bun create laddu.
  2. 02 Creates your Slack app, asks a few setup questions, signs in to your AI provider (ChatGPT, Claude, or free OpenCode), and starts as a service.
  3. 03 DMs only you at first so you can verify everything privately before inviting your team.

MIT licensed and free forever. Each person’s login lives only inside their own internet-only container—no shared keys, no vendor cloud.
