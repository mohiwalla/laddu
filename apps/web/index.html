Hand it the work, not only the question

Tag it in a channel, a thread or a DM. Every step shows up live, in plain words, and the answer lands in the same thread.

  • Reads the room

    The thread, or the channel messages before your tag, plus what’s attached: images, PDFs, zips, documents and voice notes.

  • Hands you real files

    A CSV, a chart, a Word doc, a spreadsheet, a PDF or a slide deck, uploaded to the thread.

  • Works as you

    Connect once and it reads and acts in Azure DevOps and Microsoft 365, mail, calendar, OneDrive, SharePoint, Teams and Planner, seeing only what you can.

  • Ships code

    Give it a task on Azure Repos or AWS CodeCommit. It works on its own branch, runs the repo’s checks and opens a pull request as you.

  • Remembers you

    Who you are and how you like answers, without being told to. It can search your past conversations and writes itself how-tos when it works something out.

  • Keeps time

    Reminders and recurring work, like “every Monday at 9, summarize #sales”, and DMs to people on your behalf.

Each person gets a computer of their own

A desktop with a browser, files that stay between conversations, and the internet. laddu clicks and types its way through the sites no API reaches.

  • Watch it from laddu’s Home tab in Slack, take over with one click, then hand it back
  • Internet only, with no way into your servers, your network or anyone else’s computer
  • Your ChatGPT sign-in never goes inside. A small proxy on the host adds it

Call it Jalebi, if you like

Everyone sets up their own laddu on its Home tab: a name, a face from the mithai gang or an upload, and the brain behind it. Every message it posts for you wears that name and face, so the whole thread sees it.

The brain is Codex on your ChatGPT plan, or OpenCode’s free models, with the model and how hard it thinks.

One command on a Linux server

laddu runs on any Linux box with systemd. The installer adds Docker and Bun if they’re missing, then asks a few questions.

curl -fsSL https://laddu.wtf/install.sh | sh

Already have Bun and Docker? bun create laddu does the same

  1. Makes the Slack app

    Send one command in Slack and type back the code it shows.

  2. Signs in to ChatGPT

    Open a link on any device. On a server, paste back the address the browser ends on.

  3. Asks a few questions

    Its name, who can use it, Docker or not, a public address, and the model.

  4. Says hi

    It starts as a service and DMs you when it’s up. At first it answers only you.
